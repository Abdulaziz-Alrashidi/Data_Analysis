SpaceX Falcon 9 First Stage Landing Prediction

This repository contains a comprehensive data analysis project focused on understanding and predicting the success of SpaceX Falcon 9 first-stage landings. It demonstrates end-to-end data analysis workflows, from raw data collection to feature engineering, exploratory analysis, and predictive modeling using Python.

Project Focus

The main goal of this project is to extract actionable insights from historical SpaceX launch data, identifying patterns, trends, and factors that influence the success of rocket landings. This project emphasizes rigorous data preparation, detailed exploratory analysis, and reproducible results, highlighting strong analytical and technical skills.

Data Analysis Highlights

Multi-source Data Integration: Combined structured data from the SpaceX API with supplementary information scraped from Wikipedia, ensuring a complete and reliable dataset.

Data Cleaning & Transformation: Detected and resolved missing values, duplicates, and inconsistencies; standardized columns, engineered new features, and prepared data for analysis.

Exploratory Data Analysis (EDA):

Statistical summaries and visualizations to uncover trends and correlations.

SQL-based queries to analyze and aggregate key metrics.

Interactive geospatial analysis using Folium to identify patterns across launch sites.

Feature Engineering & KPIs: Created meaningful features and key performance indicators (KPIs) to enhance analytical insights and support predictive modeling.

Data-driven Insights: Analysis revealed trends such as increased landing success with flight experience, payload effects on orbit success, and geographic advantages of launch sites.

Predictive Modeling: Developed and compared multiple classification models (Logistic Regression, SVM, KNN, and Classification Trees) to predict landing success, with model evaluation emphasizing accuracy and interpretability.
